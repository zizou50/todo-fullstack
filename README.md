# Todo Fullstack

This repository contains the fullstack todo application:

- `todo.backend` — Spring Boot backend API
- `todo.frontend` — Next.js frontend UI

## Run locally

### Backend

```bash
cd todo.backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd todo.frontend
npm install
npm run dev
```
